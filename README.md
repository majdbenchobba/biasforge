# BiasForge

Trading tools and market research.

## Scope

- Chart tools and benchmark comparisons.
- Macroeconomic news and economic-event research.
- Trade review and research records.

Features and access may change during development. Benchmark results require review and do not establish future trading performance.

Proprietary project. This repository contains an overview only; application source, trading logic, and operational data are not publicly distributed.
